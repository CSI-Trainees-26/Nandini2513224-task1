UNISphere - CSI Task-1

FILES:
1. index.html       -> First page / student login
2. home.html        -> Home page
3. colleges.html    -> College exploration page
4. compare.html     -> College comparison page
5. placements.html  -> Placement statistics page
6. dashboard.html   -> Student dashboard
7. style.css        -> Common styling for all pages


HOW TO START
Enter anything in both fields and click "Login & Explore".

NOTE- Because this project is required to use ONLY HTML and CSS, it cannot
actually check whether a username/password is correct as that requires javascript and backend.

Navigate through the navbar.
Then opens home.html after which you can explore and open various other pages.


NOTE- All college names, rankings, ratings, fees, packages and placement
statistics in this project are fictional/sample data.
